# interview-concern-review

一个面向面试复盘的 skill，帮助根据录音转写稿识别面试官的顾虑、犹豫点与隐性拒绝信号，并给出：

- 关键顾虑的证据
- 严重程度判断
- 根因分析
- 可执行改进动作
- 改写后的回答示例
- 下次面试前的准备清单

## 适用场景

- 用户提供面试录音文字稿
- 需要复盘某场面试是否被说服
- 想找出面试官真实顾虑，而不是只看“有没有收到 offer”
- 需要针对性更新回答和准备材料

## 内容说明

主文件：

- [skill.md](skill.md)

该 skill 会引导分析过程，包括：

1. 识别面试结构与考察点
2. 提取明确/隐含顾虑信号
3. 分析顾虑来源（专业、表达、动机、可信度等）
4. 按严重程度排序
5. 给出可练习的改写回答
6. 提供反问点评和行动清单

## 使用方式

将仓库中的 skill 内容按你当前的 AI/agent 配置加载即可，之后在需要复盘某场面试时直接使用。
